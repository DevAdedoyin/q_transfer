# Local Money Transfers

Q-Transfer supports domestic transfers in supported markets.

## Typical Flow

Customer initiates transfer → account and transaction checks → fraud and compliance screening → processing → settlement → recipient notification.

## Transaction States

- Created
- Pending
- Processing
- Completed
- Failed
- Cancelled
- Reversed

A completed transaction should have the necessary audit and settlement records.

## Failed Transfers

Failed transactions should be investigated using transaction status, error information, ledger records, and settlement information before support staff provide a final explanation.
